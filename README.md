# Intern Management System (Mobile App)

A cross-platform mobile application developed using **Flutter**, **Firebase Authentication**, and **Cloud Firestore** to manage intern profiles, assigned tasks, and performance tracking through a centralized platform.

The application provides interns with secure login access, personalized dashboards, and the ability to view their assigned tasks and monitor their progress. Administrators can add, update, and review intern profiles while tracking overall progress and task completion.

## Features

- Secure User Authentication
- Intern Profile Management
- Add and Update Intern Profiles
- View Assigned Tasks
- Personalized Intern Dashboard
- Task Progress Tracking
- Task Completion Monitoring
- Admin Dashboard
- Intern Performance Tracking
- Real-Time Database Synchronization
- Centralized Intern Management
- User-Friendly Interface
- Cross-Platform Mobile Application

## Technologies Used

- **Flutter** – Cross-platform mobile application development
- **Dart** – Programming language
- **Firebase Authentication** – Secure user authentication
- **Cloud Firestore** – Real-time database management
- **Firebase** – Backend services and data synchronization

## Project Overview

The Intern Management System is designed to simplify and improve the management of interns, assigned tasks, and performance tracking.

Interns can securely log in to the application, access their personalized dashboards, view assigned tasks, and monitor their progress.

Administrators can manage intern profiles by adding, updating, and reviewing information. They can also monitor task completion and evaluate overall intern performance through a centralized management system.

The application uses Firebase Authentication for secure login and Cloud Firestore for real-time database management, ensuring efficient data storage and synchronization.

## Application Workflow

1. Users open the mobile application.
2. Interns securely log in using Firebase Authentication.
3. Interns access their personalized dashboards.
4. Interns view their profiles and assigned tasks.
5. Interns monitor their task progress and completion status.
6. Administrators access the admin dashboard.
7. Administrators add, update, and review intern profiles.
8. Administrators monitor overall progress and task completion.
9. Intern information and task updates are managed through Cloud Firestore.

## Installation and Setup

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Firebase account
- Git

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Intern-Management-System.git
```

### Navigate to the Project

```bash
cd Intern-Management-System
```

### Install Dependencies

```bash
flutter pub get
```

### Firebase Configuration

1. Create a Firebase project.
2. Register your Android or iOS application.
3. Configure Firebase in your Flutter project.
4. Add the required Firebase configuration files.
5. Enable Firebase Authentication.
6. Create and configure Cloud Firestore.
7. Set up appropriate Firestore security rules.

### Run the Application

```bash
flutter run
```
